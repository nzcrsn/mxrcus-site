# Creative Direction

## Project
Marcos Ullauri — Visual Storytelling Portfolio Website

## Approved decisions
- Core concept: **A Living Archive of Stories**.
- The site is a digital exhibition, not a generic photography template.
- Photography is the primary visual element.
- Marcos is positioned as a photographer, content creator and visual storyteller, with **Memorias y Trayectorias** as a meaningful documentary/media pillar.
- Visual tone: cinematic, editorial, documentary, premium, human, minimal.
- References are inspiration only; no exact layouts, typography treatments, motion sequences or navigation patterns are to be copied.

## Recommendations
- Use image-first storytelling and large editorial type.
- Organize work around stories/projects rather than a flat Instagram-like grid.
- Use dark visual environments so photography provides most of the color.
- Keep motion restrained and intentional.

## Assumptions
- The final content set will include strong photography, selected commercial work, documentary stories and brand collaborations.
- Final client logos, biography, contact information and image permissions are pending.

## Open questions
- Final primary positioning label: Photographer / Visual Storyteller / Documentary Creator / Content Creator.
- Whether Memorias y Trayectorias is a primary navigation pillar or a subordinate category.
- Final language strategy: Spanish-only or bilingual.
- Final level of homepage experimentation.

## Approved extension — Coberturas & Transmisiones

The portfolio includes a dedicated audiovisual pillar for live transmissions, event coverage, streaming and recap work. It follows the same "Living Archive" concept: motion is presented editorially rather than as a generic video grid. Photography remains the primary visual identity, while audiovisual work demonstrates Marcos' broader production capabilities.

Approved homepage order now includes: Hero → Selected Stories → Coberturas & Transmisiones → Brands / Collaborations → Memorias y Trayectorias → About → Contact.
