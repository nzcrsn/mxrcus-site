# Marcos Ullauri — Visual Stories & Memories

Initial implementation of Marcos Ullauri's portfolio website. The product direction is a cinematic editorial archive for photography, branded work, audiovisual coverage/live transmissions, and **Memorias y Trayectorias**.

## Stack

- Next.js App Router
- TypeScript
- CSS Modules / global CSS design tokens
- Native CSS + IntersectionObserver for motion
- Static export for Cloudflare Pages

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run build
```

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `out`
- Node.js: 22 recommended

## Content

The implementation ships with placeholder project records, abstract placeholder imagery, and lightweight placeholder video previews for the Coberturas & Transmisiones section. Replace these with Marcos' final photography, verified client logos, biography, contact information, and approved copy before production release.
